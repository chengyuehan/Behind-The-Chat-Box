A scale primer · LLM context windows

It reads 2,000,000 tokens at once.

A model's context window is how much text it can hold in mind at one time — measured in tokens. How much is that, really? Here each window shares one line with the tokens of text in books you know (a book's word count × ≈4/3). Read it directly: a 128K window is about one Hobbit; today's longest windows take in the entire Harry Potter series in a single prompt.

One row per model, sorted by context size. Dots fill leftward to the token count on the right. Famous books sit on the same line at their own token length — so you read each window as "this many books of text."
METHOD · Context-window sizes come live from the LLM Stats API (loading…): context lengths from the gateway catalog, release dates from the stats catalog, joined by model id. The window is the maximum input the model accepts, in tokens. Book figures use published word counts converted to tokens at ≈4/3 tokens per word — a page 300 words · a magazine feature 5K · a research paper 8K · Animal Farm 30K · Gatsby 47K · The Hobbit 95K · Moby-Dick 206K · War and Peace 587K · Harry Potter series 1.08M words. Anchors are tuned to the context range (≤2M tokens); larger texts would sit off-scale.
